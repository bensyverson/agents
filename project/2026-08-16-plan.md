# agents: shared AGENTS.md across repos

*2026-08-16 — plan*

## Problem

Every repo carries a hand-copied `AGENTS.md` (`CLAUDE.md` is a symlink to it). About 55% of each file is universal working rules, ~20% stack rules, ~15% opt-in workflow modules, ~10% genuinely project-specific. Copy-paste has drifted: Go repos tell agents to read "DocC documentation", one file has a template hole, two state the TDD rule twice in different words, one lost "never amend". Every good edit has to be hand-carried to dozens of repos, and the global `~/.claude/CLAUDE.md` contradicts every repo on planning.

Meanwhile project-specific traps accumulate in a never-ending "Traps" section, and about a third of alpha's are not alpha traps at all — they are subagent-delegation traps that two other repos would benefit from today.

## Constraints (decided 2026-08-16)

- **Harness-agnostic.** OpenCode and others read `AGENTS.md` too, so no `@imports`, no `.claude/rules` path scoping. Mandatory content is **inline** in one checked-in file.
- **Checked into each repo**, both so any harness or collaborator sees it and so it is a live record of the house rules at that point in time.
- **Gotchas are a checked-in convention** (`project/gotchas.md`), not a database.
- **Separate repo and tool** — `agents`, a small Go CLI on Cobra. Jobs stays about tasks.
- **Principles are defaults, not laws** (file sizes are approximate; `map[string]any` is not banned).
- **No eval harness.** The real eval is daily driving it. Confined to eight repos for now; ~two dozen would opt in.

## Shape

```
AGENTS.md                              ~80 lines for a Go repo (vs. 200–400 today)
├── project-owned head                 overview · wayfinding · docs pointers
├── <!-- agents:begin core@a1b2c3 -->  universal working rules            (generated)
├── principles                          defaults, inline                   (generated)
├── stage-build                         swapped for stage-live at launch   (generated)
├── go | swift+swiftui | python | web   stack rules                        (generated)
├── docs                                backlog.md, dated project/ docs    (generated, opt-in)
├── delegation-brief                    6 lines + pointer to full file     (generated, opt-in)
└── project-owned tail                  anything written by hand, incl. curated Traps

project/gotchas.md                      project-owned, agent-appendable, seeded from a template
project/agents/delegation.md            full worktree workflow + traps + briefing template   (generated file, opt-in)
project/agents/evidence.md              measurement / verification epistemics             (generated file, opt-in)
.agents.yaml                            manifest: modules, in order
CLAUDE.md -> AGENTS.md
```

Everything outside a marker pair is project-owned; `sync` only touches marked regions and the generated files. Regions are content-addressed (`core@a1b2c3` = first 6 hex of SHA-256 of the module body), so staleness is a hash compare.

Modules are markdown in `modules/`, `go:embed`-ded into the binary — the tool version *is* the standards version and `go install` is the publish step. `--modules <dir>` overrides for iterating. Modules of `kind: file` (frontmatter) render to `path:` instead of inline. No templating in v1: project heads name paths and commands; modules speak generically.

Feedback loop is diffing: agents may edit `AGENTS.md`; `agents diff --all` shows every hand-edit inside a generated region across registered repos plus every `rule:` entry in `gotchas.md`. That is the review queue for changing the shared rules. `sync` refuses to clobber a hand-edited region without `--force`.

## CLI

| Verb | Does |
|---|---|
| `agents init [--modules a,b,c]` | write `.agents.yaml`, render `AGENTS.md` (existing content becomes the project-owned head), seed `project/gotchas.md`, symlink `CLAUDE.md`, register the repo in `~/.config/agents/repos` |
| `agents sync [--force]` | re-render stale regions and files; stop and show the diff if a region was hand-edited |
| `agents diff [--all]` | hand-edits inside generated regions + `rule:` gotchas |
| `agents status [--all]` | per repo: modules, stale?, unrendered edits, gotcha count and oldest entry |

> **Correction (2026-08-16, as built):** the module list for `init` is `--with a,b,c`; `--modules <dir>` is a persistent flag on every verb that overrides the embedded modules. `sync` also takes `--all` (visits every registered repo, non-zero exit if any refused). `status` also counts missing and orphaned regions. `$AGENTS_REGISTRY` overrides the registry path. See the README.

## Migration of the eight repos

For each of alpha, timetattle, delta, nobedan, OperativeKit, Penumbra, kura, Jobs: choose modules, run `init` against the existing file, then hand-prune the head so it holds only project-specific content. Project-specific traps move to `project/gotchas.md`; general ones are already in the `delegation`/`go` modules. Delete the Planning line from `~/.claude/CLAUDE.md`.
